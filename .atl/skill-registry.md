## How to read this registry

1. The orchestrator extracts `name` and the trigger phrase from each
   skill's `description` frontmatter.
2. When a task matches a trigger, the orchestrator injects the exact
   `SKILL.md` path into the sub-agent's launch prompt as
   `## Skills to load before work`.
3. Sub-agents MUST read those `SKILL.md` files before doing any task work.
